# Agent 任务模板

在实现或评审一个 Agent 任务前，复制下面的模板并补全内容。明确任务边界和验收
条件，有助于减少工具误用、无效重试和无法验证的输出。

## 任务定义

- **目标**：Agent 最终需要完成什么？
- **输入**：输入来源、格式及必填字段是什么？
- **输出**：输出格式、保存位置或返回对象是什么？
- **不在范围内**：本次任务明确不处理哪些内容？

## 验收条件

- [ ] 输出符合约定格式
- [ ] 关键结论可追溯到输入或可靠来源
- [ ] 失败和跳过项被明确记录
- [ ] 未执行超出任务权限的操作
- [ ] 已运行相关测试或验证命令

## 失败处理

- **可重试错误**：说明重试次数、间隔和停止条件。
- **不可恢复错误**：停止执行并返回已完成步骤、错误原因和建议动作。
- **输入不足**：列出缺失信息，不猜测会显著影响结果的内容。
